CFData Desktop 便携版

使用方法
1. 将整个 CFData-Desktop 文件夹解压到可写目录，例如 C:\Tools\CFData。
2. 双击 CFData-Desktop.exe。
3. 请将 EXE、cfdata-config.json 和下载的缓存文件保留在同一文件夹中。

说明
- 请勿在 ZIP 压缩包内直接运行 EXE。
- 首次启动会自动创建 cfdata-config.json，并在需要时下载数据缓存。
- 一键更新只替换 CFData-Desktop.exe，会保留本文件夹内的配置和缓存。
- 请解压到普通可写目录，不建议放入 Program Files，以便一键更新正常替换程序。
